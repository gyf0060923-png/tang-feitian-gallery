# 天衣飞扬 · 唐代飞天交互展馆

横向沉浸展台，以敦煌真实壁画为展品。支持年代筛选、拖拽平移、缩放、放大镜、画面取色，以及金尘浮游、沿真实飘带流动的粒子、画外触点散花和原图采色粒子显影。

选择「衣带流光」后点击金色引线触发；鼠标移动影响流速。点击壁画外的空白区域散花。右上角可关闭全部动效，默认尊重系统减少动态效果设置；切到后台时暂停动画。所有动效均为独立叠层，原始壁画和来源保持可见。

## 运行与部署

静态网站，无需安装依赖。GitHub Pages 发布 `main` 分支根目录，入口为 `index.html`。
