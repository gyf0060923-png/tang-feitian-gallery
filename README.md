# 一袖千年 · 唐代飞天交互展馆

横向沉浸展台，以敦煌真实壁画为展品。默认显示敦煌研究院原图；开启「AI修复」后，全展馆统一显示修复示意。支持年代筛选、拖拽平移、缩放、放大镜和当前画面取色。切换作品时，上一幅化成细粒子，形成有前后纵深与透视的立体螺旋；每一行粒子都沿同一方向旋转一圈，顺势展开并到达下一幅的位置，中途不倒转或停顿；全程约 1 秒，采用缓入缓出的曲线速度，静止时显示清晰图像。

保留少量画外细尘，右上角可关闭动效；默认尊重系统减少动态效果设置，切到后台暂停。没有持续的粒子画面、衣带流光或黑洞排斥。所有图片都有敦煌研究院来源链接。

## 运行与部署

静态网站，无需安装依赖。GitHub Pages 发布 `main` 分支根目录，入口为 `index.html`。

## AI修复示意

工具栏的「AI修复」切换整个展馆的原图 / AI修复示意模式，不打开弹窗。全部十二幅主图和缩略图同步切换；当前缩放位置保留，漫游、放大镜、取色和一秒立体螺旋粒子切换继续可用，再次点击恢复全部原图。吹横笛飞天的原画足部保护及色调校准合成到同一展示源，供这些工具统一使用。修复结果由内置 imagegen 基于对应的敦煌研究院原图生成，不是文物修复结论、敦煌古画原貌或敦煌研究院成果。原图文件不覆盖，修复图保存在 `assets/restored/`；提示词和对应关系记录在该目录的 `PROVENANCE.md`。

## 唐代飞天实拍索引

`photos.html` 收录36条数字敦煌官方飞天实拍资源，筛选初唐、盛唐、中唐，提供洞窟筛选、关键词检索和逐张官方详情入口。这里展示平台公开的带水印预览（最长边400像素），保留水印、原有画幅及色彩；它们不是已经获取的高清原图。官方标注的原始尺寸与本地预览尺寸分别记录在 `assets/photos/SOURCES.json`。高清文件需登录官方按平台规则获取。主展台12幅原图、修复模式和粒子切换不受影响。

## 磨砂玻璃界面

`polish.css` 统一顶部栏、侧栏、缩略图、筛选按钮、看图工具、画框和图册卡片的磨砂透明表面、柔和轮廓和高光。背景为深棕黑底及低饱和赭红、石绿晕染；标题使用轻宋体层级。保留原有交互、官方壁画色彩、减少动态效果设置，并为减少透明度偏好提供实色回退。
