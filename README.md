# 一袖千年 · 唐代飞天交互展馆

横向沉浸展台，以敦煌真实壁画为展品。默认显示敦煌研究院原图；开启「AI修复」后，全展馆统一显示修复示意。支持年代筛选、拖拽平移、缩放、放大镜和当前画面取色。切换作品时，上一幅化成细粒子，形成有前后纵深与透视的立体螺旋；每一行粒子都沿同一方向旋转一圈，顺势展开并到达下一幅的位置，中途不倒转或停顿；全程约 1 秒，采用缓入缓出的曲线速度，静止时显示清晰图像。

保留少量画外细尘，右上角可关闭动效；默认尊重系统减少动态效果设置，切到后台暂停。没有持续的粒子画面、衣带流光或黑洞排斥。所有图片都有敦煌研究院来源链接。

## 运行与部署

静态网站，无需安装依赖。GitHub Pages 发布 `main` 分支根目录，入口为 `index.html`。

## AI修复示意

工具栏的「AI修复」切换整个展馆的原图 / AI修复示意模式，不打开弹窗。全部18幅主图和缩略图同步切换；当前缩放位置保留，漫游、放大镜、取色和一秒立体螺旋粒子切换继续可用，再次点击恢复全部原图。吹横笛飞天的原画足部保护及色调校准合成到同一展示源，供这些工具统一使用。修复结果由内置 imagegen 基于对应的敦煌研究院原图生成，不是文物修复结论、敦煌古画原貌或敦煌研究院成果。原图文件不覆盖，修复图保存在 `assets/restored/`；提示词和对应关系记录在该目录的 `PROVENANCE.md`。

## 唐代飞天实拍图册

`photos.html` 收录18幅无可见水印的唐代壁画照片，与主展台使用同一份作品数据。每张均附来源链接，可按洞窟、时期和关键词筛选。图片保留公开文章中的原始文件、画幅和色彩。

## 磨砂玻璃界面

`polish.css` 统一顶部栏、侧栏、缩略图、筛选按钮、看图工具、画框和图册卡片的磨砂透明表面、柔和轮廓和高光。背景为深棕黑底及低饱和赭红、石绿晕染；标题使用轻宋体层级。保留原有交互、官方壁画色彩、减少动态效果设置，并为减少透明度偏好提供实色回退。

## 图片加载可靠性

展示使用 `delivery-data.js` 的内容哈希路径。完整画幅转成无损WebP，并逐张检查解码RGBA与输入完全一致；原始文件保留，已有体积更小的JPEG继续直接使用。256像素缩略图独立、延迟加载。此前确认的吹横笛飞天足部保护与腹部修正已从浏览器SVG渲染结果编入完整展示图，视觉像素不再由客户端反复合成。构建与源图记录见 `assets/delivery/MANIFEST.json`。

开启AI修复仅变更模式；选择作品时才请求当前大图，取消18幅大图的整批阻塞加载。图片请求有超时、重试和同模式备用文件；修复图不可用时可展示明确标注的原图。完全失败时保留上一幅，提供载入状态、手动重试和网络恢复后重试。切换粒子在目标图准备好后开始，仍为1秒单向立体螺旋，期间不清空原画。
