# 一袖千年 · 唐代飞天交互展馆

横向沉浸展台，以敦煌真实壁画为展品。支持年代筛选、拖拽平移、缩放、放大镜和原图取色。静止观赏时始终显示敦煌研究院真实原图；鼠标不推动或掏空壁画。只有切换不同作品时，上一幅先化成原图采色细粒子旋转形成龙卷状环绕，再凝聚成下一幅；全程约 1.5 秒，采用缓入缓出的曲线速度，完成后移除粒子层并恢复原图。

保留少量画外细尘，右上角可关闭动效；默认尊重系统减少动态效果设置，切到后台暂停。没有持续的粒子画面、衣带流光或黑洞排斥。所有图片都有敦煌研究院来源链接。

## 运行与部署

静态网站，无需安装依赖。GitHub Pages 发布 `main` 分支根目录，入口为 `index.html`。
